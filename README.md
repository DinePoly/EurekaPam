Robo Reaction Challenge

An Arduino reaction game where players must quickly press the correct button or button combination shown by the LEDs.

Them Features

* 3 LEDs and buttons
* Buzzer sound effects
* 3 lives
* Score & combo system
* 4 difficulty levels
* Endless Mode
* Reaction-time scoring

The pins

Component     Pin

Red LED - D2 
Green LED -D3 
Yellow LED - D4
Red Button - D6
Green Button - D7
Yellow Button - D8
Buzzer - D10

How to Play

Press any button to start.

Press the same button 3 times quickly to activate Endless Mode. Watch the LEDs and press the matching button(s) as quickly as possible, if you can, well, you can...

Built it with:

* Arduino UNO ( You can use any Arduino)
* LEDs
* Push Buttons
* Buzzer

React fast. Score high.
